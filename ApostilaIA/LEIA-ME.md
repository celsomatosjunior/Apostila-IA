# ApostilaIA

Apostilas de estudo (PDF + DOCX) a partir da transcrição da aula (TXT do TranscritorIA) e dos PDFs dos
slides, com IA 100% local (llama.cpp + Qwen3 / Qwen3-VL). Windows 10/11 64 bits.

| Pasta | Conteúdo |
|---|---|
| `codigo-fonte/` | código completo (programa, testes, scripts de compilação, documentação) |
| `instaladores/v1.0.0/` | `ApostilaIA-Setup-1.0.0.exe` + SHA-256 |
| `documentacao/` | arquitetura, instalação, reconstrução, licenças, relatório de testes |
| `testes/v1.0.0/` | relatório e saídas dos testes, exemplo sintético gerado, capturas da interface |
| `scripts-compilacao/` | cópia dos scripts de compilação (lançador C, montagem, NSIS, teste no Wine) |
| `configuracoes/` | configuração padrão e catálogo de modelos com SHA-256 |
| `backups/` | ponteiro para `backups/ApostilaIA/` na raiz do repositório |
