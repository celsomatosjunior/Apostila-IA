# Transcritor IA Local

Programa Windows (uso pessoal) que transcreve aulas gravadas — em áudio ou vídeo — para TXT, 100% local,
com Whisper. Versão atual: **2.0.0** (18/10/2026).

| Pasta | Conteúdo |
|---|---|
| `codigo-fonte/` | Projeto completo e compilável da versão atual (programa, testes automatizados, ferramentas, scripts de compilação) |
| `documentacao/` | Instalação e uso, manual completo, novidades, validação, licenças, tela |
| `testes/v2.0.0/` | Relatório de testes da 2.0.0 e evidências (logs do pytest, Wine, tempos) |
| `scripts-compilacao/` | Como compilar (os scripts ficam em `codigo-fonte/build/`) |
| `instaladores/v1.0.0/`, `instaladores/v2.0.0/` | Instaladores de cada versão + SHA-256 |

Backups independentes (ZIP do código, instalador, SHA-256): `../backups/TranscritorIA/v1.0.0/` e `v2.0.0/`.
Neste repositório a versão atual (2.0.0) está em `codigo-fonte/`; o código completo da 1.0.0 está no ZIP de
`../backups/TranscritorIA/v1.0.0/`.
