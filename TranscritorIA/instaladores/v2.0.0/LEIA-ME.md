# Transcritor IA Local 2.0.0 — instalador (Windows 10/11, 64 bits)

**Novo:** transcreve também videoaulas (MP4, MKV, AVI, MOV, WMV, WEBM, MPG, M4V, FLV), lendo somente o áudio.

1. Baixe `TranscritorIA-Setup-2.0.0.exe` e execute. Se já tem a 1.0, basta instalar por cima:
   modelos baixados, configurações, glossário, calibração e trabalhos interrompidos são mantidos.
2. Se aparecer "O Windows protegeu o computador", clique em *Mais informações → Executar assim mesmo*.
3. Abra o programa, arraste as aulas (áudio ou vídeo), escolha a pasta e clique em **Iniciar transcrição**.

Conferir o download: `certutil -hashfile TranscritorIA-Setup-2.0.0.exe SHA256` e comparar com `SHA256SUMS-2.0.0.txt`.

Voltar para a 1.0: desinstale e instale `../v1.0.0/TranscritorIA-Setup-1.0.0.exe` (os dados do usuário são mantidos).
